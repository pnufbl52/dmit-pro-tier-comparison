## FAQ：买之前最常问的 5 个问题

**Q：DMIT Pro Tiny 的流量超了怎么办？**
超出套餐流量后，带宽会被限速到 1Mbps，不会直接断线也不会额外扣费。如果经常超量，升级到 Starter 档或者购买流量包更合适。

**Q：IP 被墙了能换吗？**
可以，在控制台提交工单申请更换 IP，收费标准视节点而定，香港节点换 IP 费用约 $5。频繁被墙的话建议考虑换节点而不是反复换 IP。

**Q：支持 IPv6 吗？**
Pro 系列套餐默认分配 IPv4，部分节点支持申请 IPv6，具体在下单页面有标注。东京和洛杉矶节点目前支持 IPv6。

**Q：DMIT 和搬瓦工 CN2 GIA 比哪个好？**
两家都走 CN2 GIA 线路，网络质量接近。DMIT 的优势在于香港和东京节点的覆盖，以及控制台功能更现代；搬瓦工的优势是套餐流量更大、价格有时更低。具体选哪个取决于你的节点偏好。

**Q：可以用来搭建代理吗？**
DMIT 官方不限制合法用途，服务条款里禁止的是滥用（DoS、垃圾邮件等）。具体使用场景请自行判断是否符合当地法规。
